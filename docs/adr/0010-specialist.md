# ADR 0010: Specialist-only standalone review prototype

Date: 2026-09-24

Status: **Owner-authorized provisional scope**

## Context

The project must preserve reproducibility and distinguish development, confirmation and provisional downstream work. See the [current report](../REPORT.md) for measured evidence.

## Decision

Deliver a local HTML review demonstration; preserve original predictions separately from review edits, undo and exports. Consumer expansion ended.

## Alternatives and consequences

The requested static deliverable does not implement the full planned EDF-to-inference service. Synthetic demo content must remain labeled.

## Verification and revisit condition

Local browser acceptance; no clinical workflow certification. Revisit only through an explicit versioned decision; preserve prior evidence and confirmation exposure history.
